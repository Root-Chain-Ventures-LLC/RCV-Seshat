RCV Community License (see [LICENSE](LICENSE)). It is **not an open-source
project**, and we do not accept code contributions.

- **Pull requests are not accepted** and will be closed without review. Anything
  submitted anyway is governed by Section 5 of the LICENSE (No Contributions; Feedback).
- **Bug reports and feature requests** are welcome as GitHub Issues on this repository.
  Please use synthetic data: no real device names, addresses, communities or credentials.

  in [SECURITY.md](SECURITY.md).
