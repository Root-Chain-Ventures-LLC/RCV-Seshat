  SOURCE ADDRESSES
{{- if eq .Values.intake.service.externalTrafficPolicy "Local" }}
  externalTrafficPolicy is Local: traffic goes only to pods on the node that received it, so the sender's source
  address reaches Seshat unchanged. Two consequences:
    * the load balancer must health-check the nodes (kube-proxy answers on healthCheckNodePort) so that only nodes
      that run a ready pod receive traffic; MetalLB and cloud balancers do this when the Service has Local policy;
    * spread the collector pods over the nodes that receive traffic. A node without a ready pod gets nothing.
{{- else }}
  WARNING: externalTrafficPolicy is {{ .Values.intake.service.externalTrafficPolicy }}. kube-proxy then rewrites the source address
  (SNAT) to a node address whenever a packet is forwarded to a pod on another node. Every device would look like
  the same few node addresses: enrichment, the device knowledge base and per-sender limits break. Set
  intake.service.externalTrafficPolicy=Local, or use hostNetwork, or a balancer that does not SNAT (IPVS DSR).
{{- end }}

{{- end }}
{{- end }}
